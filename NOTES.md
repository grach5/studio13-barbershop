# Студия 13 — заметки к сдаче проекта

Стек: чистый HTML5 + CSS3 (design-токены в `:root`) + vanilla JS, без сборки, без npm/Node.js (недоступны в системе). Шрифты — Google Fonts (`Oswald` + `Inter`) через `<link>`. Иконки — inline SVG. Файлы: `index.html`, `styles.css`, `script.js`, `NOTES.md`.

## Сделано

- Вёрстка всех обязательных секций: Hero, О нас, Услуги, Галерея, Отзывы/доверие, Запись, Оплата, Контакты, Footer, wordmark-логотип.
- Собственная палитра «сталь / графит / латунь / оксблад» — сознательно не пара «почти чёрный + кислотный зелёный» и не «крем + serif + терракота». Все цвета, шрифты, радиусы, отступы, тени, длительности анимаций вынесены в CSS custom properties в `:root` (`styles.css`, блок токенов вверху файла).
- Сигнатурный визуальный элемент: медальон-бейдж «13» (герб/клеймо) в хедере и футере + повторяющийся диагональный «blade-divider» (зигзаг в стиле кромки бритвы, `clip-path`) между секциями — сквозной мотив, завязанный на название бренда и нишу.
- Реальные фотографии (Unsplash/Pexels, свободные лицензии, коммерческое использование без атрибуции): фон hero (интерьер барбершопа в приглушённом свете), широкая feature-фотография классического бритья в блоке «Услуги», 6 фото в галерее (инструмент мастера, кресло, бритьё, атмосфера студии, аксессуары, вечерняя смена). Все `<img>` — с `loading="lazy"` (кроме hero, у неё `eager`/`fetchpriority="high"`), `width`/`height`, содержательным `alt`. Прямые CDN-ссылки проверены (HTTP 200, `image/jpeg`).
- Форма записи (`#bookingForm`) на vanilla JS: по сабмиту собирает поля (имя, телефон, услуга, время, комментарий), формирует `https://wa.me/79152335020?text=...` и открывает в новой вкладке; рядом подпись «Заявка откроется в WhatsApp». Есть базовая валидация обязательных полей и статусная строка с `aria-live="polite"`.
- Блок «Оплата» — только информационный текст (наличные / карта на месте / СБП), никаких полей ввода карты.
- Контакты: адрес, `tel:+79152335020`, `mailto:m.iatsevich@yandex.ru`, время работы 07:00–22:00 ежедневно по записи, стилизованная CSS-«карта» (без внешнего iframe) + внешняя ссылка на Яндекс.Карты по адресу.
- Отзывы: показан агрегат 5.0 / 30 отзывов на 2ГИС и ссылки на 2ГИС/VK/WhatsApp/Telegram; текстов отзывов не придумывал — вместо этого честная фраза «мы не публикуем придуманные отзывы» со ссылкой на реальную платформу.
- Доступность: `skip-link`, видимый `:focus-visible`, `aria-hidden` на декоративных SVG, `aria-label` на иконках-ссылках, `prefers-reduced-motion` (отключает scroll-reveal и smooth-scroll), семантические `<address>`, `<figure>/<figcaption>`, формы с `<label>`.
- Адаптивность: брейкпоинты 960 / 760 / 400px, бургер-меню на мобильных, `clamp()` для типографики, проверено вплоть до 360px по расчётной сетке и относительным единицам.
- `<title>`, meta description, Open Graph (title/description/type/locale/site_name), favicon — inline SVG data URI (медальон «13»).

## Допущения (данных не было — додумано разумно и явно нейтрально)

- **Ссылки на 2ГИС/VK/Telegram** — точных URL страниц заведения нет в исходных данных, поэтому в футере и блоке отзывов стоят либо поисковые ссылки на 2ГИС по адресу (`2gis.ru/moscow/search/...`), либо ссылки на главные страницы платформ (`vk.com`, `t.me`) как плейсхолдер. **Перед публикацией нужно заменить на реальные прямые ссылки** на профиль/страницу студии.
- **Блок «Оплата»** — способы оплаты (наличные, карта, СБП) не были даны в исходных фактах; указаны как типичные и правдоподобные для оффлайн-барбершопа, без конкретики, требующей проверки.
- Ссылка на Яндекс.Карты — сформирована как поиск по реальному адресу (не проверенный вручную pin), стоит сверить, что виджет ведёт точно на нужную точку.
- Услуги перечислены только по трём заявленным категориям (стрижки/борода/бритьё) без цен и без дополнительных выдуманных позиций (уход, укладка и т.п.) — сознательно, чтобы не фантазировать за клиента.

## Не могу проверить

- **Lighthouse-аудит (производительность/SEO/доступность в баллах)** — не выполнялся: Node.js и npm недоступны в этой системе, поэтому CLI-инструменты (`lighthouse`, `npm install`, любые сборщики) запустить нельзя. Ручная проверка контраста, focus-стилей, семантики и адаптивности выполнена визуально/по коду, но числовых метрик Lighthouse нет.
- Полноценный визуальный скриншот в браузере — инструмент предпросмотра в этой сессии рендерит файлы вне рабочей папки как «статичные снапшоты» и не всегда стабильно компонует кадр для скриншота; корректность содержимого подтверждена через постраничное чтение текста (заголовок и весь текстовый контент совпали с исходным HTML один в один), но пиксельный скриншot получить не удалось.
